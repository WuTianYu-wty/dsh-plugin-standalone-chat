# DeepSeek Harness 项目选择器

为新会话提供并列的“选择项目”和“不选择项目”按钮，沿用 Harness 的原生工作区菜单与主题。

## 使用

- **选择项目**：使用原生工作区按钮打开菜单；当前项目名保留原生显示，长名称自动省略。按钮始终作为真实菜单锚点，保留原生键盘、焦点与弹层定位行为。
- **不选择项目**：打开 `~/.dsh/scratchpad` 独立临时工作区，由 Harness 创建或复用其中的空白会话。
- **快捷键**：`Ctrl+Alt+N`，macOS 为 `Cmd+Alt+N`。

“不选择项目”表示无需选择自己的项目。Harness 的新会话仍需要真实工作区，因此临时会话会归入侧边栏的 `scratchpad` 工作区，不会归入“未分组”。工具操作的工作目录为此临时目录；它不是操作系统沙盒，仍遵循 Harness 的权限设置。

选中态来自实际会话所属工作区。切换期间按钮禁用，失败时显示错误并允许重试；插件不修改输入框的原生禁用状态，也不替换菜单项目。

## 安装与生效

将此插件加入 Harness profile。客户端界面修改可通过重新加载窗口生效；首次安装或升级服务端临时工作区初始化逻辑后，需要完整重启 Harness。

当前本地安装使用 profile 中的链接：

```text
~/.dsh/profiles/desktop/node_modules/@local/standalone-chat
```

## 开发与验证

```sh
npm test
```

测试无需第三方依赖，执行实际客户端/服务端逻辑，检查：

- 原生菜单锚点始终可见、节点与点击/ARIA 行为保留；
- DOM 观察器收敛、按钮节点稳定、缺失控件恢复；
- 临时工作区实际选择、快速连点、可重试错误；
- 卸载时清理观察器、订阅、快捷键和插件控件；
- 服务端幂等注册临时工作区，并报告初始化失败。

菜单的真实几何定位、Escape、工作区切换和窄窗口布局还需在 Harness 桌面端验证。
